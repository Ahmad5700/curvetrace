# CurveTrace Portable v1.0.0

CurveTrace is an offline Windows app for manually extracting numerical data from
images of 2D plots.

## Start

1. Extract this ZIP file to a normal folder.
2. Double-click `CurveTrace.exe`.
3. Load a plot image.
4. Enter the X1, X2, Y1, and Y2 values and position the four calibration nodes.
5. Finish calibration, trace the curve, and export the dataset as CSV.

Microsoft Edge or Google Chrome must be installed. No internet connection,
installer, administrator access, or separate runtime is required.

## Included files

- `CurveTrace.exe` — portable Windows launcher
- `CurveTrace.html` — browser-based fallback
- `SHA256SUMS.txt` — file-integrity checksums
- `LICENSE` — MIT License

The executable is not code-signed, so Windows may identify it as an unrecognized
app. Verify the checksum or build from the public source repository if desired.

## Important

Keep backups of important datasets and projects. The initial release has
automated logic tests but has not been independently certified for critical
scientific, medical, financial, or engineering use.
