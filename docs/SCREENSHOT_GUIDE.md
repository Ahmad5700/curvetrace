# CurveTrace Screenshot Guide

Use a real app screenshot. Do not use a generated mockup as evidence of the
interface.

## Recommended setup

1. Open CurveTrace in a window around 1440 × 900 or 1600 × 900 pixels.
2. Load a clean plot that you created or have permission to publish.
3. Calibrate the plot, then finish calibration so the four nodes and guide grid
   are hidden.
4. Create two datasets with different colors and roughly 8–12 points each.
5. Place the cursor over a curve so the magnifier contains useful detail.
6. Make sure dataset names and axis values are readable.
7. Avoid personal file paths, confidential data, or copyrighted figures you do
   not have permission to redistribute.

## Capture and save

1. Press `Win` + `Shift` + `S` and select the CurveTrace window.
2. Crop only empty desktop space; keep the full left panel, plot, and magnifier.
3. Save as PNG at `docs/curvetrace-screenshot.png`.
4. Replace the placeholder file already at that path.
5. Keep the image at least 1200 pixels wide and preferably below 1 MB.

No README edit is needed when the filename stays the same.

## Optional second screenshot

A second image can show calibration mode with all four nodes and the grid. Save
it as `docs/curvetrace-calibration.png` and add this line below the first image in
`README.md`:

```markdown
![CurveTrace calibration mode](docs/curvetrace-calibration.png)
```
