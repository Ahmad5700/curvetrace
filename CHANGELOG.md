# Changelog

All notable changes to CurveTrace will be documented in this file.

## [1.0.0] - 2026-09-08

### Added

- Portable 64-bit Windows launcher with an offline HTML application
- Image loading by file picker, drag and drop, or clipboard paste
- Four-node calibration for rotated and mildly skewed axes
- Linear and logarithmic X/Y scales
- Calibration grid that is hidden during dataset tracing
- Multiple named and colored datasets
- Point creation, insertion, dragging, keyboard nudging, and deletion
- Cursor magnifier and zoom/pan controls
- Individual and combined CSV export
- Project save/open with the source image embedded
- Automated calibration and structural tests
